# Changelog

## 0.8.0

First public release packaging: portable zip, optional per-user installer, SHA-256 checksums,
optional signing, release instructions, MIT licence, About window and startup command-line helpers.

## 0.7.0

First-time setup wizard measures chin reporting, button positions, comfortable movement and jitter,
then lets users try pointer movement and physical clicks. Includes optional administrator setup.

## 0.6.0

English and Serbian Latin localization, immediate language switching, translated help and dialogs.

## 0.5.0

Touchpad selection and hot-plug support, Click lock, accidental double-click blocking and help beside
each setting. New installations use strategy 3 and position-based zones.

## 0.4.0

Settings window with a live touchpad drawing, diagnostic bundles, merging of split chin contacts,
and AppData settings with an explicit portable mode.

## 0.3.0

Physical-click button zones, filtering of Windows clicks, click sounds and Start at login.
The 0.3.1 follow-up added settling time, landing/position zone modes and a taller default strip.

## 0.2.0

Background cursor movement from raw touchpad reports, a tray icon, pause hotkey and movement settings.

## 0.1.0

Initial Raw Input diagnostics, HID capability dumps and CSV recordings for finger and chin contacts.
